# prompts/

Integral record of every prompt session on this repository, per the Prompt Sessie Documentatie
Protocol in `Meta_Master/CLAUDE.md`.

One file per session: `YYYY-MM-DD_<slug>.md`, with frontmatter `date`, `repo`, `status`
(`open|pending|done`) and `resume` (a short trigger sentence). A session with `status: open` or
`pending` and a non-empty `resume` appears in `Meta_Master/RESUME.md` and in `/checkresume`.

The point is not bookkeeping. It is that the reasoning behind a decision outlives the session that
made it — including the decisions to *not* do something.
